✨ ABOUT

PRECORDER is an in-game video recording mod for Minecraft Java Edition, built around a configurable recording system and FFmpeg-powered MP4 encoding.

Control your recordings directly from Minecraft with customizable video quality and convenient keyboard shortcuts.

🚀 MAIN FEATURES

Feature| Description
🎥 Video Recording| Capture Minecraft gameplay
📦 MP4 Export| Save recordings in MP4 format
⚡ FFmpeg| H.264 video encoding
🎮 In-Game Controls| Control recording without leaving the game
⏸️ Pause & Resume| Pause and continue recording
📁 Auto Folder| Organized recording output
⚙️ Custom Settings| Adjust recording quality

🎛️ VIDEO SETTINGS

Choose your recording quality

Resolution| Quality
480p| Low
720p| HD
1080p| Full HD

Frame Rate

- 30 FPS
- 60 FPS
- 120 FPS

Bitrate

Customize your video bitrate from 2 Mbps to 50 Mbps.

HUD Control

Choose whether the Minecraft HUD appears in your recordings.

🎮 KEYBOARD SHORTCUTS

Key| Action
F8| Open PRECORDER Menu
F9| Start / Stop Recording
F10| Pause / Resume

⚙️ SETTINGS INTERFACE

PRECORDER provides an in-game menu for managing recording and changing supported settings.

- Select video resolution.
- Change FPS.
- Adjust bitrate.
- Enable or disable HUD visibility.
- Start, stop, pause, and resume recordings.

📂 RECORDING LOCATION

Your recordings are automatically stored in:

p-recordings/

Video format: ".mp4"

Video codec: H.264

📱 PLATFORM

Current target: Android ARM64

The project is built for Minecraft Java Edition using Fabric.

🧩 REQUIREMENTS

- Minecraft Java Edition 1.21.11
- Java 21
- Fabric Loader 0.18.0+
- Fabric API
- Android ARM64 FFmpeg native libraries

🔨 BUILD

Clone the repository and run:

./gradlew build

Windows:

gradlew.bat build

Build output:
